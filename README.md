## Abstract

Academic institutions routinely generate large volumes of student data—attendance, internal assessment scores, assignment submissions, and attendance patterns—yet this data is rarely used to its full potential for early intervention. GradeMind is an AI-based academic performance prediction and student analytics system designed to address this gap by leveraging machine learning to forecast student outcomes and identify at-risk learners well before final examinations. The system aggregates historical and ongoing academic records, applies feature engineering to capture patterns such as attendance consistency, assignment completion rates, and trends across internal assessments, and trains predictive models—including regression and ensemble-based classifiers—to estimate a student's likely academic performance. A web-based dashboard presents these predictions alongside visual analytics, enabling faculty and academic mentors to identify students who may need additional support and to track cohort-level trends over a semester. By combining predictive analytics with an intuitive interface, GradeMind aims to support data-driven decision-making in academic mentoring, reduce dropout and failure rates through timely intervention, and give students actionable feedback on their own progress. The project also explores the interpretability of the underlying models, ensuring that predictions are accompanied by clear, explainable factors rather than opaque scores, so that both educators and students can trust and act upon the insights generated by the system.

## Setup & Execution Instructions

> Update this section as the project's tech stack is finalized in `src/`.

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd KLH-CSE-2026-2420030165-GradeMind
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r src/requirements.txt
   ```
4. Configure the data source as documented in `data/README.md`.
5. Run the pipeline / application:
   ```bash
   python src/main.py
   ```
6. Outputs (metrics, plots, predictions) are written to `results/`.
